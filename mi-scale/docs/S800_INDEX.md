## 🔑 Ключевые выводы из исследования

### Протокол связи
- **UUID сервиса**: `0000fe95-0000-1000-8000-00805f9b34fb` (Mi Beacon, MiOT)
- **Компания**: 911 (0x038F) - Xiaomi Inc.
- **Шифрование**: AES-CCM с 128-битным bindkey
- **Локальное имя**: `Mijia Scale S800 XXXX` (где XXXX — последние 4 символа MAC)

### Типы пакетов (из реальных данных)

| Тип | Frame Control | Длина | Описание |
|-----|---------------|-------|----------|
| Beacon (idle) | `0x10` | 12 байт | Маячковый пакет в режиме ожидания |
| Beacon (active) | `0x10` (0x5B) | 12 байт | Устройство активировано |
| Measurement (open) | `0x58` | 20 байт | Открытый пакет с данными (частично) |
| Measurement (encrypted) | `0x48` | 24 байта | Зашифрованный пакет с измерениями |

### Критические параметры

```yaml
MAC: D4:43:8A:CD:3F:76  # Реальный MAC из логов
Product ID: 0xE251      # S800 идентификатор
Model: xiaomi.scales.ms116
Local Name: "Mijia Scale S800 3F76"
```

### Пример зашифрованного пакета

```
Raw: 48 59 e2 51 0a 9e c3 04 5d f1 8a ef de c8 83 fd a3 00 00 00 ba c0 76 7f

Структура:
- 0x48: Зашифрованный фрейм
- 0x59 0xE2: Product ID
- 0x0A: Frame Counter
- ef de c8 ... 7f: Ciphertext (требуется bindkey для расшифровки)
```

## ⚠️ Критически важная информация

### Без Bindkey
- ❌ Невозможно получить данные о весе
- ❌ Невозможно получить данные об импедансе
- ❌ Невозможно рассчитать метрики тела
- ✅ Можно определить активность устройства (idle/measuring)

### С Bindkey
- ✅ Полный доступ к весу пользователя
- ✅ Биоимпеданс для расчёта состава тела
- ✅ BMI, жировая масса, мышечная масса, вода, кости, и т.д.
- ✅ Поддержка нескольких пользователей
- ✅ Автоматическое определение пользователя по весу

**Вывод**: Bindkey является обязательным требованием для работы с S800.

## 🛠️ Технические требования

### Минимальные требования
- Home Assistant OS / Supervised
- Bluetooth адаптер с поддержкой BLE 4.0+
- Python 3.9+
- Библиотеки: `bleak`, `paho-mqtt`, `pycryptodome`

### Рекомендуемые требования
- Bluetooth 5.0+ адаптер
- Расстояние до весов: < 5 метров
- MQTT broker (Mosquitto)
- Bindkey устройства (обязательно!)

### Дополнительные зависимости (для S800)

```txt
# Добавить в requirements.txt
pycryptodome>=3.19.0  # Для AES-CCM расшифровки Mi Beacon
```
